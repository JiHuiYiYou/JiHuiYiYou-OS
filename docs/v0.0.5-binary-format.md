## § 1 Goals + 5 原则 compliance

### 1.1 设计目标

jhyy_OS kernel 走 `kernel.efi`(PE/COFF,被 UEFI 协议锁,per **D1** 2026-08-04)。但 kernel 起来之后跑的 **user-space 程序**格式由 kernel 决定,有完全自由度。

**三选一决策**(2026-09-04 user 锁):
- ❌ PE/COFF:Windows 遗产 + header 臃肿(~1KB),为 OS-native use 浪费
- ❌ ELF:工具兼容但哲学别扭(自研 OS 跑 Linux 二进制),且 `*T` 语义跟 musl 对齐负担
- ✅ **.jhyynb(本 spec)**:jhyy 原生格式

**最终态覆盖范围**:
1. **jhyy_OS user-space 程序**(M5b 后,即第一个真 user-space 服务上线后)
2. **jhyy 编译器自身**(M11 时,jhyy 编译器在 jhyy_OS 上跑也用 .jhyynb)
3. **完整 DWARF 子集**(支持 GDB attach — `jhyy-gdbstub` daemon 喂 DWARF 给 GDB)

### 1.2 5 原则 compliance(per `v0.0.0-design.md § 2`)

| 原则 | .jhyynb 怎么满足 |
|------|------------------|
| **可行且简单** | header 固定 **112B**(per 编译器侧 [`jhyy-binary-format-v1.0.0.md § 4`](../../JiHuiYiYou/docs/abis/jhyy-binary-format-v1.0.0.md),8-aligned,sizeof=112);section 表 32B/entry 固定;无 ELF 那种 sh_info / phdr 历史包袱;无 program header |
| **双线作战** | format 字段对应 jhyy 语言层 first-class 概念(Cap / IPC / Region),每段都推动 jhyy 编译器扩展 |
| **寄生 Windows** | 工具链开发在 Windows + MSYS2;.jhyynb loader 在 jhyy_OS kernel 上跑;QEMU + OVMF 测试 |
| **Debug 在语言里** | D41 Debug ABI 通过 `.jhyy_cap` sub-section 嵌入;DWARF 子集由 jhyy 编译器 emit;`jhyy-gdbstub` 喂给 GDB |
| **Kernel 不解决语言问题** | loader 只解析 enum / u32 / u64,不解析 jhyy 类型;.jhyy_cap / .jhyy_ipc / .jhyy_region sub-section 是 jhyy-side metadata,跟 kernel 不耦合 |

## § 2 OS 端实施要点(本节是镜像补充)

> **完整 wire-format 见编译器侧 spec** § 4-§ 14。本节只列 OS 端需要的视角。

### 2.1 loader 必须做什么(M5b+ 实施)

按以下顺序解析 .jhyynb:

1. **读 header(112B)** → 校验 magic `JBE\x01` + version + flags + target + abi_version + entry_point + stack_size + heap_hint + section_count + 5 组 table off/size(section/string/cap_init/ipc_dispatch/region)+ debug/symbol/reloc table off/size + `header_crc`
2. **读 section table(N × 32B)** → 校验 `section_count == N`,解析 kind / vaddr / file_off / file_size / mem_size / align
3. **读 string table** → 用于 section name / cap name / region name
4. **读 cap_init table** → 每条目分配 cnode slot,跳 `init_call_off`(若非零)
5. **读 ipc_dispatch table** → 注册 msg_tag → handler_fn_off 进 kernel IPC dispatch
6. **读 region table** → 初始化 region ownership(vaddr 区间 + kind 决定管理策略)
7. **mmap 所有 alloc section** → 按 `section.vaddr` 创建进程虚拟地址空间
8. **跳到 entry_point** → `section[.text].vaddr + entry_point`

### 2.2 loader 不解析什么

- **DWARF bytes**:kernel 不解析 DWARF,只在 GDB attach 时由 `jhyy-gdbstub` daemon 通过 GDB remote protocol 喂给 GDB
- **`.jhyy_cap` / `.jhyy_ipc` / `.jhyy_region` sub-section**:kernel 不读;`jhyy-inspect` / CodeGraph 在 dev tooling 里读
- **Symbol table**:kernel 不解析(用于 debug 打印 / backtrace 增强,可在 `jhyy-gdbstub` 里读)
- **Relocation table**:MVP 静态链接 = `reloc_table_off = 0`,loader 不处理

### 2.3 kernel 必须暴露什么(per D41 / D-GUI-12)

| 暴露项 | 用途 |
|---|---|
| `debug_query_kernel_state(pid) -> *KernelStateHistory` | LLM agent / jhyy-inspect 拉取进程状态 |
| 进程内存 layout(M5b process-model § 1.1) | .jhyynb section vaddr → 实际 mmap |
| Cap table 注册入口(M5b capability § 2) | cap_init table → 实际 cnode slot |
| IPC dispatch table(M5b syscall-abi § 1.1) | ipc_dispatch → handler_fn |
| Region lifecycle(per region types primary, D2) | region_table → anon_arena / mmap / raw_mmio / unsafe_share 管理 |

### 2.4 Header 字段镜像(loader 解析所需,per 编译器侧 § 4)

> **镜像范围**:loader 只关心字段名 + 顺序 + 字节大小,足以做 offset 解析;完整 c 风格 struct 定义走编译器侧 spec。**冲突以编译器侧为准**(per `coordination.md § 7` 规则)。

| 字段 | 类型 | 字节 | 用途 (loader 视角) |
|------|------|------|--------------------|
| `magic` | `[4]u8` | 4 | 校验 `JBE\x01` (per D44) |
| `version` | `u16` | 2 | 格式版本;loader 拒绝不识别 version (per D43) |
| `flags` | `u16` | 2 | bit 0=debug / 1=symbol_table / 2=relocation_table / 3=cap_init / 4=ipc_dispatch / 5=region_table / 6=pie / 7-15 reserved |
| `target` | `u8` | 1 | 0=`amd64_jhyy_os`,预留 1=aarch64 / 2=riscv64 |
| `abi_version` | `u8` | 1 | 对齐 `jhyy-abi-v1.x.x` 主版本 |
| `_pad0` | `u16` | 2 | 显式 padding(8 对齐下一字段) |
| `entry_point` | `u64` | 8 | .text 段内偏移(loader 算真实入口 = `section[.text].vaddr + entry_point`) |
| `stack_size` | `u64` | 8 | 初始栈大小(per-thread;kernel 创建时 mmap) |
| `heap_hint` | `u64` | 8 | 初始 heap 起点 hint(user std malloc first-fit 起跳点) |
| `section_count` | `u16` | 2 | section table 条目数 |
| `_pad1` | `u16` | 2 | padding |
| `section_table_off` / `section_table_size` | `u32` / `u32` | 4 + 4 | section table 文件偏移 + N × 32B |
| `string_table_off` / `string_table_size` | `u32` / `u32` | 4 + 4 | string table 偏移 + 大小 |
| `cap_init_off` / `cap_init_count` | `u32` / `u16` | 4 + 2 | cap init table 偏移 + 条目数;0 = 无 |
| `_pad2` | `u16` | 2 | padding |
| `ipc_dispatch_off` / `ipc_dispatch_count` | `u32` / `u16` | 4 + 2 | IPC dispatch table 偏移 + 条目数;0 = 无 |
| `_pad3` | `u16` | 2 | padding |
| `region_table_off` / `region_table_count` | `u32` / `u16` | 4 + 2 | region table 偏移 + 条目数;0 = 无 |
| `_pad4` | `u16` | 2 | padding |
| `debug_off` / `debug_size` | `u32` / `u32` | 4 + 4 | debug group 偏移 + 大小;0 = 无 |
| `symbol_table_off` / `symbol_table_size` | `u32` / `u32` | 4 + 4 | symbol table 偏移 + 大小;0 = 无 |
| `reloc_table_off` / `reloc_table_size` | `u32` / `u32` | 4 + 4 | reloc table 偏移 + 大小;0 = 无 |
| `header_crc` | `u32` | 4 | CRC32(header[0..104])(不包自身 4B + 尾 padding 4B);loader 校验 |
| `_pad5` | `u32` | 4 | 尾 padding(8 对齐收尾) |
| **总** | | **112** | 8-aligned;loader 一次性读 112B |

**重要变更记录**:
- 2026-09-05 撤回旧值 "header 固定 64B"(per 早期草案残留);**真实尺寸 = 112B**(per 编译器侧 spec § 4 line 47 + line 136 sizeof 验证);若按旧 64B 实现会解析错位 — Q-OS-010 (closed per audit)

## § 3 D-lock 对位(OS 侧视角)

| D-lock | 内容 | OS 端 loader 怎么用 |
|---|---|---|
| **D1** | Boot 走 UEFI + PE/COFF | kernel.efi 不变;.jhyynb 仅 user-space |
| **D2** | Region types primary | § 9 region_table 用 kind 字段管理(anon_arena / mmap / raw_mmio / unsafe_share) |
| **D6** | `Cap<T>` 8B layout | § 7 cap_init_entry 跟 cnode 内存 byte-equal(sprint 3g.7 联调验证) |
| **D11** | M1-M3 `*mut T`,M4+ `&mut` | loader 不感知;.jhyynb 由 jhyy codegen 决定 emit 什么 |
| **D13 / D20** | `#[ipc_handler]` attribute | § 8 ipc_dispatch;kernel 按 msg_tag 查 dispatch |
| **D16** | Cap-offset 表 wire format | § 8 `cap_off_table_off`;kernel 接 ipc_call 后按 cap_offsets 原地改写 cnode_idx |
| **D17** | `IoResult<T>` 单态化 | 不影响 .jhyynb |
| **D22** | arena.jhyy 不扩展 | § 9 region_table 用 cap+offset 自管 |
| **D23** | Phantom sentinel + codegen skip | § 7 cap_init_entry **不进** `_phantom` 字段;loader 不分配 phantom 内存 |
| **D40** | wire-format 表达规则 | 链表字段 = `*T`(8B),数组字段 = `[*]T`(16B);loader 按此访问 wire-format 字段 |
| **D41** | Debug ABI 锁 | § 12 debug group 子结构;`.jhyy_cap` 段 ProvenanceInfo seed;kernel introspection syscall `debug_query_kernel_state` |
| **D-GUI-12** | M3 syscall = MS x64 + naked interrupt | § 8 IPC dispatch 走函数指针,无 syscall 指令编码 |
| **D42** | asm 走 QBE .s 工具链(过渡) | § 10 .text 段容许 inline asm 块 |
| **D43** | byte-equal 阶段性 self-equal | § 4 `version` 字段跨大版本 bump;loader 拒绝不识别的 version |
