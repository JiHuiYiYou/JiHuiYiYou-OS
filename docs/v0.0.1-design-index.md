## § 3 跟 jhyy 编译器 roadmap 关系(2026-08-04 修订)

- capability 编译器层约束 → v3.x P1 之一(sprint 3g + 3g.5 + 3g.7)
- OS 实际编码窗口 = **v3.x P0(3a-3f)完成之后**(M1 硬前置)
- **OS 早期原型不能用 C 端临时编**(2026-08-04 澄清)— C 版 jhyy.exe 缺全部 6 P0 特性,编不出 OS(详见 `memory/project_jhyy_os_kickoff.md` "纯 jhyy from day 1 精确语义")
- v2.x N 代期间 OS 团队**只能**推 v0.0.x 设计 doc + 跨边界对齐(coordination.md)
